# 📝 jspad.dev Feedback & Issues

Welcome to the official feedback and issue tracker for [jspad.dev](https://jspad.dev) — a powerful and modern playground for writing and testing JavaScript, TypeScript, HTML, and CSS.

This repository is dedicated to collecting:

- 🐞 Bug Reports  
- 💡 Feature Requests  
- ❓ Questions or Confusions  
- 📢 General Feedback

We’d love your help to improve jspad.dev!

---

## 📬 How to Contribute

Please use the [Issues](https://github.com/your-org/jspad-feedback/issues) tab to submit:

### 🐞 Bug Reports

If you encounter unexpected behavior, please open an issue with:

- What you were trying to do
- What happened instead
- Steps to reproduce the issue
- Screenshot or screen recording (if possible)
- Browser and OS info

### 💡 Feature Requests

Have an idea to make jspad.dev better? We'd love to hear it! Include:

- What the feature should do
- Why it's useful
- Any similar tools that do this well (optional)

### ❓ Questions

Not sure how something works? File a question — others might have the same one.

---

## 📌 Tips for Filing Issues

- Search existing issues before creating a new one.
- Keep issues focused: one problem or request per issue.
- Use clear titles like `Bug: Console not updating after edit` or `Feature: Add support for localStorage`.

We’ll use this repo to post changelogs and updates — click the 🔔 “Watch” button above to stay in the loop.
